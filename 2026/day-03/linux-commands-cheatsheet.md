# Day 03 – Linux Commands Practice

## Commands are:
  ### Process Management
  - ps -> to get snapshot of all processes which are running 
  - top & htop -> to get the realtime view of processes which are running
  - kill & pkill -> to terminate the processes with PID and name
  ### File Management
  - ls -> to list all the files and directory present on current directory.
  - ls -a -> to list all files and directory including hidden ( the directory starts from .)
  - pwd -> to get the path of our current directory.
  - cd <directory> -> to change our directory eg: cd devops/: will change your directory to devops/.
  - cd .. -> to come out from the present directory.
  - mkdir <directory> -> to create directory.
  - rmdir <directory> -> to delete empty directory.
  - touch <filename> -> will create an empty file.
  - rm <filename> -> will delete the file.
  - cp <source> <destination> -> will copy the sourcefile to destination.
  - mv <source> <destination> -> will move/rename the source to destination.
  - cat <filename> -> will display the contents of file.
  ### Networking commands
  - ping <destination> -> to check whether the host is reachable or not.
  - ip addr -> to get the ip address of the machine.
  - netstat -> to moniter network statistics
  - curl -> the command used to test the http/API endpoint.
  - wget -> used to download something from the internet.
  
## Why This Matters for DevOps
Real production issues are solved at the command line.

The faster you can inspect logs and network issues, the faster you can:
- Restore service
- Reduce downtime
- Gain trust as an operator
